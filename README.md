# MathLens

**输入公式或上传图片，得到清楚、可复制的数学计算结果。**

> 已打通 Python API 的 LaTeX 算术化简切片，其他功能仍在开发中。

## 它能帮你做什么

MathLens 希望让公式计算更方便：

1. 输入一段公式，或上传公式图片。
2. 检查识别出的内容，有错可以修改。
3. 选择化简、求导、积分或解方程。
4. 查看结果，并复制为 LaTeX（常用的数学公式排版格式）。

能给精确结果时，优先给精确结果。例如，解 `x² = 2` 时先给出 `x = ±√2`，需要时再显示小数近似。暂时算不出来时，会说明原因；适合用数值方法的问题，再尝试求近似值。

## 计划提供的功能

- **公式输入**：粘贴 LaTeX 公式，直接计算。
- **图片输入**：识别图片中的公式，确认后再计算。
- **手动选择**：自动判断要做什么，也允许你自己指定运算和变量。
- **计算步骤**：先从部分积分问题开始，逐步增加。
- **本地使用**：提供本地网页和桌面窗口；准备好依赖和识别模型后，无需联网使用。

能处理哪些公式、能否给出步骤，都有范围限制。近似求根找到一个答案，也不代表已经找到全部答案。

## 目前做到哪了

现在可以通过 Python API 准备和化简标量算术表达式，返回精确结果、原式条件
和 LaTeX。解析与计算在独立进程中执行，包含总时限、取消与资源回收。
CLI、图片识别、求导、积分、求解和界面尚未接入；S1 的其他验收项仍在推进。
当前代码只保留数学核心和实际运行的执行接口，外围功能在实现时再定义接口。

例如，在项目环境中运行以下脚本（Windows 使用进程启动保护）：

```python
from mathlens.application import run
from mathlens.schemas import ComputeRequest, LatexInput, SimplifySpec


if __name__ == "__main__":
    response = run(ComputeRequest(
        input=LatexInput(latex=r"\frac{1}{3}+\frac{1}{6}"),
        operation=SimplifySpec(),
    ))
    print(response.status)  # success
    print(response.latex)   # \frac{1}{2}
```

当前切片支持整数、精确小数、变量与下标变量、整数幂、括号和分式。
函数、方程、非整数幂和内嵌微积分暂时返回明确的不支持诊断。
分式化简保留原式的分母非零条件，例如 x/x 的结果为 1，条件为 x ≠ 0。

## 项目边界

计算使用 SymPy，LaTeX 解析使用 latex2sympy2，不用大模型生成数学答案。

当前专注于公式计算，暂不做几何题理解、证明、作业批改。
