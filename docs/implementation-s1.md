# 早期实现与依赖探测记录

本文保留早期 S1 的依赖探测结论，不再定义项目接口或限制模型范围。
全项目接口统一以 [interfaces.md](interfaces.md) 和 `src/mathlens/schemas/`
为准；原先的 PreparedProblem/ComputationResult、异常驱动 prepare、通用
variables/bounds 等接口草案已被替代。

当前只有数据模型与接口声明，没有计算、OCR、JSON codec 或进程执行实现。
契约测试不代表任何数学能力已实现。

## 环境记录

早期骨架验证使用 Windows x86_64 / CPython 3.12.12。依赖版本以
`pyproject.toml` 和 `requirements-dev.lock` 为准；Python 3.11 尚无实测记录。
历史上 editable 安装、模块导入、pip check、wheel 构建和包内容检查曾通过，
不代表当前接口改动后的所有实现已验证。

## 历史解析行为

固定依赖组合的探测记录：

- `\log(10)` 曾被解析为以 10 为底的对数，不能未经验证就作为自然对数。
- `x^2-2=0` 曾直接得到已求解的等式列表，解析器并非只构造表达式。
- 某些依赖在 Python 3.13 下导入失败，当前 Python 版本限制以配置为准。

这些是历史记录，不是此次重新验证的行为。未来接入解析器必须测试原式保真、
小数精确性、下标变量、导数和积分不重复执行，以及分母约束保留。

## 后续实现应验证

- 输入规范化不能静默改变数学含义。
- 解集区分空集、全集、条件集、部分解和执行失败。
- 普通反常积分与柯西主值分别处理。
- 数值回退须具备适用范围与充分参数，不夸大解集完整性。
- worker 崩溃、EOF、损坏或过大消息、超时、取消与清理失败均有诊断。
- CLI、Web 和桌面复用应用接口和 JSON 契约。
